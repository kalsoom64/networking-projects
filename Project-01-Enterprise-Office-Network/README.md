# Project 01 - Enterprise Office Network

## Objective
Design and configure a small enterprise office network using Cisco Packet Tracer.
## Devices Used
- 1 Cisco 1941 Router
- 1 Cisco 2960 Switch
- 4 PCs
- 1 Server

## IP Addressing

| Device | IP Address |
|---------|------------|
| Router | 192.168.10.1 |
| PC0 | 192.168.10.10 |
| PC1 | 192.168.10.11 |
| PC2 | 192.168.10.12 |
| PC3 | 192.168.10.13 |
| Server | 192.168.10.100 |

## Skills Learned

- Router Configuration
- Switch Configuration
- Static IP Addressing
- Default Gateway Configuration
- ICMP Ping Testing
- Basic Network Troubleshooting
