# Project 02 - Enterprise DHCP Network

## Objective

Configure a Cisco router as a DHCP Server to automatically assign IP addresses to client PCs.

---

## Devices Used

- 1 Cisco 1941 Router
- 1 Cisco 2960 Switch
- 4 PCs
- 1 Server

---

## Network Topology

Router
|
Switch
|---- PC0
|---- PC1
|---- PC2
|---- PC3
|---- Server

---

## IP Addressing

| Device | IP Address |
|---------|------------|
| Router | 192.168.10.1 |
| Server | 192.168.10.100 |
| PCs | DHCP |
